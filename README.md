should build this" into a call to act right now — tell an AI agent on
[make.fun](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3)
what your app should do and get your first version today, free:

> Stop saying 'someone should build this' — tell an AI agent on make.fun what your app should do, and it will build your first version today, free.

`main.ts` writes the sentence to `/output/entry.txt` (with a script-relative
fallback), so it runs correctly from any working directory.
